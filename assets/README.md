# Assets - Ресурси для лендінгів

## Зображення (images/)

Додайте наступні зображення:

### Обов'язкові:
1. **hero-bg.jpg** - Фонове зображення для головної секції (1920x1080px)
   - Варіант: картки таро, затишний стіл, свічки

2. **tarot-cards.jpg** - Зображення розкладу карт (800x600px)

3. **profile.jpg** - Фото таролога (400x400px, квадрат)
   - Професійне фото в домашній атмосфері

### Додаткові (опціонально):
4. **candles.jpg** - Свічки для секції послуг
5. **crystals.jpg** - Кристали/амулети
6. **testimonial-bg.jpg** - Фон для відгуків

**Формат:** JPG або WebP (для швидкого завантаження)
**Оптимізація:** Стиснути до < 200KB кожне

## Іконки (icons/)

Додайте іконки месенджерів (SVG або PNG 64x64px):

1. **telegram.svg** - Іконка Telegram
2. **whatsapp.svg** - Іконка WhatsApp
3. **viber.svg** - Іконка Viber
4. **phone.svg** - Іконка телефону
5. **email.svg** - Іконка email

**Джерела іконок:**
- https://simpleicons.org/ (безкоштовні SVG)
- https://fontawesome.com/ (іконки)

## Шрифти (fonts/)

Рекомендовані українські шрифти:

1. **Montserrat** - для заголовків (Google Fonts)
2. **Open Sans** - для тексту (Google Fonts)
3. **Philosopher** - для декоративних елементів (українська кирилиця)

**Альтернатива:** Використати Google Fonts CDN (не завантажувати файли)

## Placeholder зображення

Поки немає реальних фото, можна використати:
- https://placeholder.com/
- https://unsplash.com/ (безкоштовні фото)
- https://pixabay.com/ (безкоштовні зображення таро)

**Примітка:** Всі зображення мають бути оптимізовані перед завантаженням на хостинг!
