# Таро у Тапочках - Лендінги для соціальних мереж

## Опис проекту

Проект створений для просування послуг таро через рекламу в соціальних мережах (Facebook, TikTok, Instagram).

**Канал:** "Таро у Тапочках"
**Позиціонування:** Легкий, домашній стиль, але з повними практиками таро
**Мова:** Українська
**Цільова аудиторія:** Україномовна аудиторія з соцмереж

## Послуги та ціни

1. **Повна діагностика** - 500 грн
2. **Чистка воском** - від 3000 до 6000 грн
3. **Захист** - 1500 грн
4. **Ритуали** - від 2500 до 80000 грн
5. **Віджиг свічками** - від 3000 до 6000 грн
6. **Чистка свинцем** - від 13000 до 16000 грн

## Технічні деталі

### Технології
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Responsive:** Окремі версії для desktop та mobile
- **A/B Testing:** 3 варіанти лендінгів для тестування конверсії

### Функціонал
- Форма зв'язку для замовлення послуг
- Кнопки прямих посилань на месенджери (Telegram, WhatsApp, Viber)
- Адаптивний дизайн
- Швидке завантаження (оптимізація для реклами)

## Концепція дизайну

### Landing 1 - "Домашній затишок"
- **Стиль:** М'які кольори (пастельні відтінки)
- **Акцент:** Домашня атмосфера, тепло, довіра
- **CTA:** "Замовити розклад"

### Landing 2 - "Містичний професіонал"
- **Стиль:** Темні кольори (фіолетові, золоті акценти)
- **Акцент:** Професіоналізм, таємниця, сила таро
- **CTA:** "Дізнатися своє майбутнє"

### Landing 3 - "Сучасний мінімалізм"
- **Стиль:** Чисті лінії, контрастні кольори
- **Акцент:** Простота, ясність, конкретика
- **CTA:** "Отримати відповіді"

## Хостинг та деплой

**Рекомендації:**
- **GitHub Pages** (безкоштовно, простий деплой)
- **Netlify** (безкоштовно, автоматичний деплой, швидкий)
- **Vercel** (безкоштовно, оптимізація)

**Вимоги:**
- HTTPS (обов'язково для реклами у Facebook)
- Швидке завантаження (< 3 секунди)
- Валідний HTML/CSS

## Метрики успіху

**Конверсія:**
- Відсоток кліків на кнопки месенджерів
- Відсоток заповнення форми
- Показник відмов (bounce rate)

**A/B Testing:**
- Порівняння конверсії між 3 варіантами
- Визначення найефективнішого дизайну

## Примітки

- Мобільна версія критично важлива (більшість трафіку з соцмереж іде з мобільних)
- Текст має бути емоційним та переконливим (домашній стиль)
- Важливо додати соціальні докази (відгуки, якщо є)
- Зображення мають бути оптимізовані (WebP формат)
